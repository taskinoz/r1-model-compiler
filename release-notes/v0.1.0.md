First release of `r1studiomdl`, a native Titanfall 1 / Titanfall Online MDL v52 compiler for QC, SMD and DMX sources, with a Python v52 decompiler and validation tools. It is part of a family with [r2-model-compiler](https://github.com/taskinoz/r2-model-compiler) (Titanfall 2, MDL v53).

Validation of this source (compiler unchanged since the corpus runs). The corpus and in-game results below were measured with a local build, SHA-256 `eb0b03953ebf9d7154f1e06c6fdbd769f837ec4e798582bed52b1f7fac9947cc`; the executable in the ZIP was built by the release workflow on GitHub's runner from the same commit, so its hash differs, and it passed the regressions and package check below:

- All 3,514 Titanfall Online models and 4,130 of the 4,131 unique original Titanfall models decompile, recompile and match in every compared field (bones and bind pose, geometry, materials, sequences, animation world positions, IK, attachments, hitboxes, procedural bones and PHY). The remaining model is a retail file whose sequences point at missing animations.
- Rebuilt original-Titanfall models were compared with the originals in R1Delta: 26 / 26 pairs match (attachments over 1,871 animated samples within 0.0004 in and 0.0001 deg, identical bounds and collision traces, physics rest within 0.04 in). Rebuilt models also render and animate like the originals in the Titanfall Online client.
- 62 Python regressions and both CTest groups pass; the extracted ZIP's three examples compile, decompile and recompile using only the packaged files and the Python standard library.

The ZIP contains the compiler, the Python tools (decompiler, reader, round trip, in-game harnesses), documentation and authored examples. Python 3.10+ is needed for the tools; the compiler runs on its own. No game assets are included: extract models from your own install.

See [VALIDATION.md](https://github.com/taskinoz/r1-model-compiler/blob/v0.1.0/VALIDATION.md) for the evidence and its limits. This validates the tested corpora and representative in-game cases, not every possible source input.
